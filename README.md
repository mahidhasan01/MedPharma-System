# PharmaFX – Pharmacy Management System

A JavaFX-based Pharmacy Management System designed to manage medicines, inventory, suppliers, customers, prescriptions, orders, and sales operations through a structured desktop application.

## 📌 Project Overview

PharmaFX is a desktop pharmacy management application developed using Java and JavaFX. The system provides a structured platform for managing common pharmacy operations and organizing pharmaceutical data.

The project focuses on providing a user-friendly interface while maintaining organized application logic and modular components.

## ✨ Key Features

- 💊 Medicine Management
- 📦 Inventory Management
- 👥 User and Customer Management
- 🏪 Supplier Management
- 📝 Prescription Management
- 🛒 Order Management
- 💰 Sales Management
- 📊 Pharmacy Data and Management Operations
- 📄 Document and Data Management
- 🔄 Multi-module application structure
- ⚠️ Custom exception handling

## 🧩 Main Modules

The system includes several major functional areas:

- **User Management** – Handles user-related information and operations.
- **Inventory Management** – Organizes medicine and stock-related information.
- **Prescription Management** – Manages prescription-related operations.
- **Order Management** – Handles pharmacy order processes.
- **Supplier Management** – Maintains supplier-related information.
- **Sales Management** – Supports pharmacy sales operations.
- **Document & Data Management** – Organizes application data and records.
- **Pharmacy Analytics** – Supports pharmacy-related data management and analysis.
